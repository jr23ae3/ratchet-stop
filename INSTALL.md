# Install LetsGetPaid (public)

Anyone can install from this repo:

1. **Clone or download** this repository.
2. Open Chrome → `chrome://extensions` → enable **Developer mode**.
3. Click **Load unpacked** and select this **repository root** folder (not `release/`).
4. Open [Vest Markets](https://next.vestmarkets.com), sign in, open a chart.
5. Use the **LetsGetPaid** panel (bottom-left). Toggle with `Alt+Shift+B`.

License enforcement is **off** in the default `license/config.js` — no key required.

Support the project with Vest checkout code **AEthatsMe**.

Maintainers: run `npm run build:release` for an obfuscated `release/` build before Chrome Web Store upload.
