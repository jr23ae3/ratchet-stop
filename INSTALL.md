# Install Ratchet Stop (public)

1. **Recommended:** [Latest GitHub release](https://github.com/jr23ae3/ratchet-stop/releases/latest) → download `ratchet-stop-v*-extension.zip` → unzip → Chrome **Load unpacked** → that folder (obfuscated build).
2. **From source:** clone this repo → **Load unpacked** → repo root (readable JS; for development).
3. Open [Vest Markets](https://next.vestmarkets.com), sign in, open a chart.
4. Use the **Ratchet Stop** panel (bottom-left). `Alt+Shift+B` toggles visibility.

No license key — `license/config.js` has `enabled: false`. Support code **AEthatsMe** on Vest checkout.
